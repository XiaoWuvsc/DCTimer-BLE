核心功能

智能

  • 兼容 GAN、魔域、奇艺等主流智能魔方
  • 优化打乱推进/纠错体验，跟手更跟心
  • 视角可拖动的 3D 实时虚拟魔方
  • 快速连接，无需获取 MAC 地址

改进

  • 手动输入计时自动分割成绩段落
  • 成绩列表 PB 历程标注和智能排序
  • 补全 WCA 观察模式语音提醒
  • 底层升级，新安卓设备更稳定流畅

数据迁移与使用说明

  1. DCTimer-BLE 与原 DCTimer 是不同的包名，无需担心安装覆盖或冲突，可同时存在。
  2. 完全兼容原 DCTimer 数据，从原软件导出并导入 .db 文件即可完成数据迁移。
  3. 若导出失败，请尝试将导出路径中的 DCTimer/ 部分删除，仅保留根路径下的 database.db 文件。
  4. 对于奇艺智能计时器，使用前需同时长按两个按键完成重置，再连接 App。
  5. 遇到任何问题，欢迎加入反馈交流群或提交 GitHub Issue。

提示：迁移前建议先备份原数据，确保万无一失。
